# Active Directory Home Lab

## Objective
Built an Active Directory home lab using Windows Server and virtual machines to practice Windows administration, user management, networking, and domain services.

## Tools Used
- Windows Server
- Windows 10/11
- VirtualBox / VMware
- Active Directory Domain Services (AD DS)

## What I Practiced
- Installing Active Directory
- Creating users and groups
- Configuring Organizational Units (OUs)
- Joining a client PC to a domain
- Basic Windows administration
- Troubleshooting networking or login issues
